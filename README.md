objetivo deste software é servir como um monitor de Home Server leve, simples e focado na praticidade. Com ele, você pode centralizar os links dos serviços executados no seu servidor e acompanhar, em tempo real, o uso de CPU, Memória RAM e o espaço em disco. É a solução ideal para quem utiliza servidores Windows e busca uma ferramenta direto ao ponto, sem a complexidade de grandes plataformas de monitoramento. Nota de segurança: A senha padrão de acesso é admin123 e pode ser facilmente alterada no Arquivo SenhaConfig.java : private static final String SENHA_PADRAO = "admin123";
